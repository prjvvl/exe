exe github.com/prjvvl/exe

Run your local apps from one place.

exe <app> <command> resolves to a shell command and runs it in your current terminal, driven entirely by a plain config file you edit yourself, not by anything baked into the tool.

irm https://raw.githubusercontent.com/prjvvl/exe/main/install.ps1 | iex

Downloads a prebuilt binary for your OS/arch from the latest release and wires up the shell hook automatically, no runtime required. Restart your terminal afterward.

How it works

1exe nav projectscd into a folder you defined
2exe open vscodelaunch an app on its default path
3exeno args, browse everything in a menu

Config, not code

~/.config/exe/config.toml

[[apps]]
name = "nav"
description = "Jump to common folders"

  [[apps.commands]]
  name = "projects"
  run = "cd ~/projects"

Built in

exe infoself-describes exe and its current config, the entry point for pointing an AI agent at it
exe viewprints the raw config file
exe editopens the config file in your editor
exe updatechecks for and installs the latest release
